OWASP A02:2021 — Cryptographic Failures

Weak cryptography exposes sensitive data through broken algorithms, insecure modes,
insufficient key lengths, or improper random number generation.

ALGORITHMS TO AVOID
--------------------
- MD5, SHA-1          → broken, use SHA-256 or SHA-3
- DES, 3DES           → weak, use AES-256
- RC4                 → broken
- AES/ECB mode        → reveals patterns, always use CBC or GCM
- Math.random()       → not cryptographically secure, use SecureRandom

REQUIRED FIXES
--------------
Weak cipher mode → switch to AES/GCM:

    // BEFORE (vulnerable)
    Cipher cipher = Cipher.getInstance("AES/ECB/PKCS5Padding");

    // AFTER (secure)
    Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
    byte[] iv = new byte[12];
    SecureRandom.getInstanceStrong().nextBytes(iv);
    cipher.init(Cipher.ENCRYPT_MODE, key, new GCMParameterSpec(128, iv));

Weak hash → replace with SHA-256:

    // BEFORE (vulnerable)
    MessageDigest md = MessageDigest.getInstance("MD5");

    // AFTER (secure)
    MessageDigest md = MessageDigest.getInstance("SHA-256");

Weak key generation → use SecureRandom:

    // BEFORE (vulnerable)
    KeyGenerator kg = KeyGenerator.getInstance("AES");
    kg.init(128);

    // AFTER (secure)
    KeyGenerator kg = KeyGenerator.getInstance("AES");
    kg.init(256, SecureRandom.getInstanceStrong());

Missing KeyGenerator init (CWE-325):
    // The fix is to call keyGen.init(keySize) before keyGen.generateKey()
    KeyGenerator keyGen = KeyGenerator.getInstance("AES");
    keyGen.init(256);
    SecretKey key = keyGen.generateKey();

OWASP RULES
-----------
- Use AES-256-GCM for symmetric encryption
- Use SHA-256 or SHA-3 for hashing
- Always initialize KeyGenerator with a key size
- Use SecureRandom for all cryptographic randomness
- Never hardcode keys or IVs
